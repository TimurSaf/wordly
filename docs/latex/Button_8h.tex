Заголовочный файл с классом \doxylink{classButton}{Button} для создания и отображения интерактивных кнопок. 

Данный файл содержит объявление класса \doxylink{classButton}{Button}, который отвечает за отображение прямоугольной кнопки с текстом, обработку её состояния наведения мыши и нажатия.
