\doxysubsection{Подробное описание}
Класс для управления сеткой догадок в игровой механике. 

\doxylink{classGuessGrid}{Guess\+Grid} создаёт сетку из \doxylink{classPuzzleLetter}{Puzzle\+Letter}, отображает её, обрабатывает ввод с аппаратной клавиатуры (буквы, удаление, Enter), проверяет догаданные слова и формирует результаты (цветовые правила) для виртуальной клавиатуры.
