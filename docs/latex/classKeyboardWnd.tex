\doxysubsection{Подробное описание}
Класс виртуальной клавиатуры для ввода символов. 

Класс \doxylink{classKeyboardWnd}{Keyboard\+Wnd} наследуется от \doxylink{classWndInterface}{Wnd\+Interface} и реализует окно с набором кнопок, расположенных по форме клавиатуры внизу экрана. Позволяет обрабатывать клики и наведение мыши по кнопкам, возвращает идентификатор нажатой клавиши и окрашивает кнопки по правилам.
