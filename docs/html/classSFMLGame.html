Подробное описание

Класс, управляющий окном SFML и игровым циклом.

Класс SFMLGame инициализирует окно для игры, загружает шрифт, запускает и контролирует основной игровой цикл до завершения.

◆ gameLoop()

void SFMLGame::gameLoop ( )

Запускает основной игровой цикл.

В безусловном цикле обрабатывает события окна, обновляет состояние игры и выполняет отрисовку до тех пор, пока окно не будет закрыто.

◆ loadFont()

sf::Font SFMLGame::loadFont ( )
static

Загружает и возвращает шрифт для использования в игре.

Выполняет загрузку файла шрифта из заранее известного пути и возвращает объект sf::Font. В случае неудачи бросает исключение.

Возвращает
sf::Font Загрузка шрифта, готового к использованию.
Исключения
std::runtime_errorЕсли не удалось загрузить файл шрифта.
