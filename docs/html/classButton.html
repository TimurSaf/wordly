Подробное описание

Класс, реализующий интерактивную кнопку с текстом.

Класс Button предоставляет функциональность для создания графической кнопки с возможностью отображения, изменения цвета при наведении и клике. Каждая кнопка имеет уникальный actionID, который позволяет различать действия при её нажатии.
