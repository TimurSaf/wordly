Подробное описание

Класс, представляющий одну букву в игровом поле пазла.

Класс PuzzleLetter позволяет отображать символ в прямоугольной области, задавать его значение, изменять цвет фона в зависимости от состояния решения (CORRECT, WRONG_POS или NO_STATE) и получать текущее состояние буквы.

Перечисления

◆ SolutionState

enum PuzzleLetter::SolutionState

Перечисление возможных состояний буквы при решении пазла.

NO_STATE - состояние по умолчанию (буква ещё не проверялась), CORRECT - буква стоит на правильном месте, WRONG_POS - буква присутствует в слове, но в неправильной позиции.

◆ setSolutionState()

void PuzzleLetter::setSolutionState ( const SolutionState &  solutionState)

Устанавливает состояние решения для этой буквы.

Изменяет цвет фона в зависимости от переданного состояния:

  • CORRECT: фон зелёный (буква на своём месте),
  • WRONG_POS: фон жёлтый (буква есть в слове, но не на этой позиции),
  • NO_STATE: фон серый (состояние по умолчанию).
Аргументы
solutionStateСостояние решения для буквы (SolutionState).
Возвращает
void
Исключения
std::out_of_rangeЕсли solutionState недопустим.
