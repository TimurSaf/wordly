Подробное описание

Абстрактный базовый класс для оконных интерфейсов.

Определяет общий контракт для всех интерфейсов: обновление логики, отрисовка, обработка ввода мыши и клавиатуры, управление доступностью и получение результата работы интерфейса.

Возвращает результат работы интерфейса.

По умолчанию возвращает NothingState. Может быть переопределён для сигнализации о завершении, необходимости перезапуска и т.д.
