\doxysubsection{Подробное описание}
Заголовочный файл с базовым интерфейсом \doxylink{classWndInterface}{Wnd\+Interface} для всех оконных интерфейсов. 

Этот файл содержит объявление класса \doxylink{classWndInterface}{Wnd\+Interface}, который определяет общий интерфейс для всех окон (игровых, меню, диалогов) в приложении\+: методы обновления, отрисовки, обработки ввода и управления состоянием.

Используется для определения результата работы интерфейса\+:

\item Restart — необходимо перезапустить текущий интерфейс или игру,
