\doxysubsection{Подробное описание}
Класс, реализующий интерактивную кнопку с текстом. 

Класс \doxylink{classButton}{Button} предоставляет функциональность для создания графической кнопки с возможностью отображения, изменения цвета при наведении и клике. Каждая кнопка имеет уникальный action\+ID, который позволяет различать действия при её нажатии.
