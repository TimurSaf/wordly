\doxysubsection{Подробное описание}
Класс, управляющий окном SFML и игровым циклом. 

Класс \doxylink{classSFMLGame}{SFMLGame} инициализирует окно для игры, загружает шрифт, запускает и контролирует основной игровой цикл до завершения.
