\doxysubsection{Подробное описание}
Окно выбора длины слова перед началом игры. 

Класс \doxylink{classBeforeGameWnd}{Before\+Game\+Wnd} наследуется от \doxylink{classWndInterface}{Wnd\+Interface} и реализует интерфейс для отображения окна, в котором пользователь может выбрать длину слова перед стартом игры. Внутри окна рисуется фон, заголовок, а также кнопки, соответствующие разным вариантам длины слова.
