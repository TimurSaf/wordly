Подробное описание

Заголовочный файл с базовым интерфейсом WndInterface для всех оконных интерфейсов.

Этот файл содержит объявление класса WndInterface, который определяет общий интерфейс для всех окон (игровых, меню, диалогов) в приложении: методы обновления, отрисовки, обработки ввода и управления состоянием.

Перечисления

◆ WndResultState

enum WndResultState

Состояния, возвращаемые методом getResultState интерфейсов.

Используется для определения результата работы интерфейса:

  • NothingState — нет изменений,
  • Finished — интерфейс завершил свою работу,
  • Restart — необходимо перезапустить текущий интерфейс или игру,
  • Menu — перейти в меню,
  • Quit — выход из приложения.
Элементы перечислений
NothingState 

Нет изменений состояния.

Finished 

Интерфейс завершил свою работу.

Restart 

Требуется перезапуск интерфейса или игры.
