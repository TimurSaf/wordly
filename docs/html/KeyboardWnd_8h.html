Подробное описание

Заголовочный файл с классом KeyboardWnd для отображения виртуальной клавиатуры.

Данный файл содержит объявление класса KeyboardWnd, который наследуется от WndInterface и отвечает за отображение набора кнопок-клавиш, обработку их нажатий и наведения мыши.
