Подробное описание

Класс для управления сеткой догадок в игровой механике.

GuessGrid создаёт сетку из PuzzleLetter, отображает её, обрабатывает ввод с аппаратной клавиатуры (буквы, удаление, Enter), проверяет догаданные слова и формирует результаты (цветовые правила) для виртуальной клавиатуры.
