Заголовочный файл с классом \doxylink{classPuzzleWnd}{Puzzle\+Wnd} для отображения игрового окна пазла. 

Данный файл содержит объявление класса \doxylink{classPuzzleWnd}{Puzzle\+Wnd}, который наследуется от \doxylink{classWndInterface}{Wnd\+Interface} и обеспечивает логику и отображение основного игрового процесса\+: сетки догадок, виртуальной клавиатуры и обработку ввода пользователя (мышь и клавиатура).
